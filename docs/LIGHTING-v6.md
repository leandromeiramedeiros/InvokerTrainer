# Dynamic lighting (v6 #76) — design

Goal: spells and glowing sand are light emitters; nearby sprites/terrain are lit (diffuse + rim + soft glow) and cast perspective-correct shadows. Extends js/render/gl.js (WebGL2 compositor); the 2D path (js/render/light.js cell lights) stays as the fallback and as "Lighting: Off".

## Architecture
- Render passes (gl.js): [terrain albedo] [terrain normal+height] [sprites albedo] [sprites normal+height] -> lighting pass -> Bayer quantise (existing) -> fog/HUD. The normal+height target is RGBA8: RG = normal xy (0..1), B = height (0..1, 0 = ground), A = material (0 ground, 1 unit, 2 tree/cliff, 3 emissive).
- Light list (L1, js/render/lights.js): `IT.Lights.add({x,y,z,r,g,b,radius,intensity,kind})` per frame from fx.js/particles/sand/spells: orbs (3 per Invoker, colour by orb), Forge Spirits, Sun Strike beam, Meteor (moving), EMP, Tornado, Ice Wall sheen, TP column, torches/braziers on buildings, relic/aghs sand (clustered: k-means-lite into <= 4 lights). Cap 32 lights (uniform array), sorted by screen-space contribution; day/night ambient from js/data/daynight.js.
- Normals (L2, js/render/normals.js): bake-time for every IT.Art.sheet frame: alpha silhouette -> signed distance (8SSEDT) -> "pillow" normal (gradient of the distance, z from a dome profile), packed next to the albedo atlas; terrain normals/height from the heightmap (js/data/dotaworld.js elevation tiers + cliff edges from terrain.js edgeKind) into a second cached canvas (same cache lifetime as the terrain canvas).
- Shader (L3, gl.js): for each pixel: N from the G-buffer, h = height; for each light: L = light - (p, h), attenuation = smooth (1 - d/radius)^2 scaled by intensity; diffuse = max(0, N.L); rim = pow(1 - max(0, N.V), 3) * max(0, N.L) * rimK (V = up); glow = soft additive splat of the light colour (radius x 0.6); result = albedo * (ambient + sum diffuse) + rim + glow; quantise by the existing Bayer matrix so the look stays pixel-art (4 shade steps). Half-res light buffer on Low.
- Shadows (L4): per unit/structure/tree: a skewed silhouette quad (sprite drawn black at alpha 0.35, sheared away from the 1-2 strongest lights within radius; length = height / lightHeight x distance, skew by the light direction) drawn into a shadow buffer before the lighting pass (so shadows darken the ground, never the caster). Cliffs/trees: a 6-step heightmap ray-march in the shader toward each strong light (sample the height channel), High only.
- Settings (L5): Lighting Off/Low/Medium/High (+ Ultra, see Key light + Ultra) (#76b: 4 levels; settings.js, default Low; Off = today's 2D cell lights); perf budget 60 fps @1920x1080 with the full tree count: cap lights by distance to the camera, LOD: sprites below 6 px skip normals, tree shadows batched per chunk. Reduced-motion does not affect lighting.

## Art rules
- Lights never exceed the orb palette (Quas cyan, Wex magenta, Exort orange), Sun Strike gold, Meteor orange-red, EMP violet, sand gold; intensity so that mid-day lighting is subtle (+15% max) and night is dramatic (+60%).
- Rim only on units/trees (material 1-2), never on ground; keep readability: HP bars, status rows and text are drawn after lighting.
- Fog outside vision stays unlit (fog pass after lighting).

## Packages
- L1 (sonnet): js/render/lights.js + emitters wired in fx.js/particles.js/sand.js/units.js (orbs) + tests (list cap, clustering, sorting).
- L2 (sonnet): js/render/normals.js (8SSEDT + pillow), terrain normal/height canvas in terrain.js, atlas packing in gl.js; tests on a synthetic sprite (normals point outward, z>0 inside).
- L3 (opus): gl.js lighting pass + shader, Bayer quantise, day/night ambient, half-res path; headless shader-string tests + a browser screenshot.
- L4 (opus): shadow buffer + skewed silhouettes + heightmap ray-march (High).
- L5 (sonnet + haiku tests): settings toggle, caps/LOD, perf measurement at 1080p, before/after screenshots day + night, readability check.
Order: L1 ∥ L2 -> L3 -> L4 -> L5. Each lands behind the setting (Off by default until L5 flips the default to Low).

- L3 (2026-10-13): gl.js `comp.setLighting(off|low|medium|high)` / `IT.GL.setLighting` (dev hook; L5 wires the setting) / `IT.GL.LEVELS` {off: 0 lights; low: 8, half-res, no rim; medium: 16, rim; high: 32, rim + glow}. Pass order: scene + light grid + G-buffer (unit 6) -> `FS_LIT` diffuse buffer (half-res on low, unit 7), second run rim + glow on medium/high -> `FS_MAIN_LIT` adds the diffuse to the existing light grid before the 9-level Bayer quantise; rim/glow added in 4 dithered steps, then bloom. 'off' = the old `FS_MAIN`, bit-identical. Uniforms `uLP`/`uLC` vec3[32], `uLR` vec2[32] (radius, intensity), `uN`, `uMode`, `uRim`, `uGlow`, `uCap`; light gain capped +15% day / +60% night; fog vision in the light texture alpha. render.js: G-buffer = opaque view-size canvas (terrain normals blitted at the camera offset; every y-sorted sprite draw copied with its own pillow normals at the same rect and order, so mirrored west frames need no flip; B = height6 << 2 | material: units 1, trees/towers/buildings 2, FX 3), <= 6 sprite normal bakes per frame, `IT.Lights.begin(R)` per frame, uniforms in screen px via `IT.GL.toScreen`. Browser check (Chromium, webgl2): shaders compile, no console errors, Free Play day: 8 lights (3 Exort orbs + Sun Strike) reach the shader; the daytime effect is subtle by design (+15% cap), night + screenshots pending L5. Gaps: first terrain bake may hitch and duplicates `ter.base`; faint overlays / fill-drawn FX have no normals; WebGL1 may reject 96 uniform vectors -> falls back to off.
- L4 (2026-10-13): LEVELS gain `shadows` (off 0 / low 0 / medium 1 / high 2 lights per caster) and `march` (high). render.js records every unit/tower/structure/tree draw >= 6 px in the y-sorted pass, picks the 1-2 strongest lights reaching the caster's foot and draws sheared black silhouettes (`IT.Render.shadowXform(light, caster)` -> {sx, shear, len, ky}; len = distance / lightZ clamped 1.2) into a view-size shadow canvas that FS_LIT samples (`uShadow`, unit 3): diffuse and glow x (1 - 0.85 x shadow) on ground pixels only (units/trees never self-darken). High adds a 6-step heightmap march (`MARCH_STEPS`, 40 px, 2 lights; terrain + material 2 occlude). Budgets per frame: 120 shadow draws (40 trees), 6 silhouette bakes (cached per source canvas), one clear + one 480x270 upload. Static blob shadows untouched. Browser check: high compiles, no console errors. Gaps: day shadows subtle (+15% cap); silhouette cache stale if a source canvas is redrawn in place.
- L5 (2026-10-13): `Settings.lighting` off/low/medium/high (default low; old saves without the key read low, unknown reads off) applied through `IT.GL.setLighting` on load and on Save (Video section radio row, i18n `set.lighting.*` EN/PT in i18n/v6.js); independent of reduced-motion. `LEVELS.casters/trees` = shadow-draw budget (medium 60/20, high 120/40). `IT.Render.lightingCost()` = 60-frame average of G-buffer + shadows + present, one-time `console.info` when 'high' exceeds 6 ms (no auto-downgrade). `Lights.list` culls by view rect + 10% margin before scoring. Browser check (Chromium webgl2, Free Play): default low active on load, high at night shows the warm Exort orb glow on the ground around the hero and the Sun Strike light; off unchanged; no console errors. ## Perf measurement (2026-10-13, main session)
Setup: Pages build 060cd0d, headless Chrome, RTX 5070 Ti (ANGLE D3D11), 1920x1080, Free Play default map, vsync off, fpsCap display, 5 s per run, while a Ghidra decompile loaded the machine.
- Idle scene, day and night alike: off ~840 fps (p50 1.2 ms); low / medium / high ~630 fps (p50 1.6 ms, p99 <= 2.9 ms).
- Stress, 32 lights/frame at night: off 1054, low 725, medium 657, high 644 fps (p99 <= 2.2 ms).
- Lighting costs ~0.4 ms/frame; high is far inside the 16.7 ms 60 fps budget (and the 6 ms LC_WARN) on this GPU: no LOD changes needed. Repo before/after screenshots: dropped by the CEO.

## Key light + Ultra (2026-10-13)
Problem: with no spell cast there were no emitters, and by day the ambient grid already saturates (AMB x 1.25 > 1), so additive point light was invisible: Off/Low/Medium/High looked identical (<1% pixel diff idle).
- Key light (gl.js `keyLight(night, level)`, `KEY_DIR`, `SUN` / `MOON`): always on above Off, emitters or not. Fixed upper-left direction (screen px (-.45,-.5,.74), toward the light); sun by day (warm tint, strong), moon at night (cool, dimmer), blended by `Light.night`. FS_LIT computes a key factor `kf = 1 + (N.K - K.z) x (up | down)` (flat ground = 1, so Off-like ground stays put; sprite pillow normals and terrain slopes get a lit and a shaded side), times `1 - sh x shadow` on ground (silhouette buffer + the height march toward the key on High+), carried in the diffuse buffer's alpha (kf / 2; fog = 1). FS_MAIN_LIT: `l = clamp(floor(min(l,1) x kc x 9 + bay) / 9, 0, 1.5)`, kc = sun / moon tint on the lit side, neutral shade on the far side: visible by day because it scales the already-saturated grid. Key rim (Medium+) goes to the additive buffer.
- Key shadows (render.js `keyXform(dir, len)`, one transform for every caster): drawn in `drawShadows` before the point-light shadows, `soft` additive copies with a small shear spread (penumbra). `LEVELS.structs` false (Medium): units only.
- Emitters: hero orbs (units.js, unchanged), Forge Spirits, plus tower and building orb lamps (towers.js `lights` / `structLights` -> `IT.Lights.addPx`).
- Levels (`IT.GL.LEVELS`, `NAMES`; one FS_LIT program per level: array size + march steps are compile-time constants; a level whose shader fails steps down one level):
  - Off: FS_MAIN, bit-identical; no key.
  - Low: key diffuse (half-res buffer) + 8 point lights; no rim / glow / shadows.
  - Medium: + rim, glow, key + point shadows from units (60 casters, 1 light each), key shadow length 0.55, 16 lights.
  - High: + towers / buildings / trees cast (120 / 40 trees, 2 lights each), key 0.8 with 2-copy penumbra, 6-step march (40 px, 2 lights + key), 32 lights.
  - Ultra: full-res, 48 lights (MAXL 48: 144 + ~10 uniform vectors, inside WebGL2's 224 minimum), rim x1.35, glow x1.4, 3 lights per caster, 400 casters / every visible tree (record cap 600), key 1.1 with 3-copy penumbra, 12-step march over 64 px toward 4 lights + key, 12 normal / silhouette bakes per frame. `lightingCost` warns for high and ultra above 6 ms.
- Browser check (Chromium webgl2, Free Play day, idle, no orbs): all 5 level shaders compile, no console errors; pixels changed vs Off: low 3.8%, medium 4.7%, high 7%, ultra 8.5% (noise 0.2%); tree / tower / hero shadows fall down-right, longer per level.
- Perf: last measured ~0.4 ms/frame at High (RTX 5070 Ti, 1080p, before the key light). Ultra adds per-frame: <= 400 x (1 + 3) silhouette draws on a 480x270 canvas, 12 + 12 march taps per ground pixel, 48-light loop: expected a few tenths of a ms more on that GPU; not yet re-measured.
